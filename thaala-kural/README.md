# தாளக் குறள் · Thaala Kural

A rhythm game for children built from the metre of every Tirukkural couplet. Each அசை of a
kural is one note: **நேர்** is the orange pad "தா", **நிரை** is the teal pad "தக". The notes
scroll towards a hit ring in the order the kural is chanted, a four-beat count-in leads into the
first அடி, one rest beat separates the two அடி, and a clean சீர் pops its name (தேமா, புளிமா,
கூவிளங்காய் …). The வெண்பா metre was always the memorisation device; this makes it tappable.

Free, offline after the first visit, no accounts, no advertising, nothing leaves the device.
Central Institute of Classical Tamil, Chennai · Digital Archives.

## Where the rhythm comes from

`build/build_data.py` reads the multilingual Kural app's data bundle (`../kural-app/data/ch/*.json`),
in which every kural carries the output of the CICT reference metrical scanner
(Yappu-Metrical-Scanner, `scan_verse_best`): அடி → சீர் → அசை, each அசை typed N (நேர்) or I (நிரை)
with its letter units. The game keeps only what it needs — the அசை kind and its syllable text,
the சீர் name and class — and writes one file per அதிகாரம் to `data/ch/NNN.json` (~20 kB each)
plus `data/meta.json` (map, counts, the unplayable list). No metrical decision is made here.

## Build and run

```bash
py build/build_data.py       # data/ from ../kural-app/data
py build/make_samples.py     # assets/sfx
py build/make_icons.py       # assets/icon-*.png, app-icon.png
py build/lint_js.py app.js game.js audio.js sw.js
python -m http.server 8775 --directory "D:\DL file\thaala-kural"
```

Open `http://localhost:8775/`. Keyboard on a desktop: **F** / **←** = தா, **J** / **→** = தக,
space = tap (level 1), Esc = pause. `#/play/N?demo=1` plays a kural by itself (the "காட்டு" button);
`#/play/N?auto=1` does the same but shows the result screen, for testing — a self-played round
never earns stars.

## Timing notes

- The chart is driven from `performance.now()`; taps are judged from the pointer event's own
  timestamp, so input latency of the event loop does not count against the child.
- The **sound timing** screen (settings → 🎯) plays eight ticks and measures the mean lag of the
  child's taps; the result is applied as an offset to every judgement. Use it once per device.
- Web Audio inside Android WebView is too laggy for tap-to-sound; the Android build routes the
  drum through SoundPool instead (see `../thaala-kural-android`). The seven WAVs are the same.
- Level 1 sounds the note's own drum whichever pad is tapped, so a five-year-old hears the
  right rhythm from the first round.

## Android

`../thaala-kural-android` wraps this folder in a WebView with three bridges (drum, haptics,
text-to-speech); `build_assets.py` there copies this folder into the app's assets, so a fix here
reaches Android by re-running that one script.
