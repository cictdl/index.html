குறுக்காக இடமிருந்து வலம்

    நெடுக்காக மேலிருந்து கீழ்

      கட்டத்தைத் தொட்டுத் தொடங்குங்கள்

      பழைய கட்டங்கள்

      நாள்தோறும் ஒரு குட்டிக் கட்டம், வாரந்தோறும் ஒரு பெரிய கட்டம். எதையும் மீண்டும் விளையாடலாம்.

      குட்டிக் கட்டங்கள் (7×7)

        வாரக் கட்டங்கள் (11×11)

          குறள் குறுக்கெழுத்து என்றால் என்ன?

          ஒவ்வொரு விடையும் ஒரு திருக்குறளில் உள்ள சொல். குறிப்பு (clue) என்பது அந்தச் சொல் நீக்கப்பட்ட குறளே. கட்டத்தை நிரப்பியதும் குறள் முழுமையும், அதன் பொருளும், ஒவ்வொரு சொல்லின் இலக்கணக் குறிப்பும் காட்டப்படும்.

          Every answer is a word from a Tirukkuṟaḷ couplet; the clue is that couplet with the word blanked out. On completion the full kural, its meaning and the word-level grammar note are revealed.

          எழுத்திடும் முறை · How to type

          • ஒரு கட்டம் = ஒரு எழுத்து. க, கா, க், ஐ, ஃ ஒவ்வொன்றும் ஒரு கட்டம். One cell holds one Tamil letter (grapheme cluster): a bare consonant, a consonant with its vowel sign or pulli, or a vowel.
          • திரைப் பலகை: முதலில் மெய் (க), பிறகு துணைக்குறி (◌ா) — கா. துணைக்குறி தட்டியதும் அடுத்த கட்டத்திற்கு நகரும். மெய்யுடன் நிறுத்த, அடுத்த எழுத்தைத் தட்டுங்கள்.
          • ⌨ சாதனத் தட்டச்சு: கணினியில் தமிழ் விசைப்பலகை (Tamil99, phonetic) அல்லது கைப்பேசியில் Gboard/Sellinam தட்டச்சும் நேரடியாகக் கட்டங்களில் விழும். ெ+ா போன்ற தனித்தனி விசைகள் தானாக ொ ஆகச் சேரும்.
          • Enter / ⇄ திசை மாற்றும்; Tab அடுத்த சொல்; Backspace அழிக்கும்; அம்புக் குறிகள் நகரும்.
          • 💡 துணை: ஒரு கட்டத்தில் ஒரு எழுத்தைக் காட்டும் (ஒரு கட்டத்திற்கு 2 முறை). இலக்கணம்: தேர்ந்த சொல்லின் இலக்கணக் குறிப்பைக் காட்டும். ✓ சரிபார்: தவறான எழுத்துகளைச் சிவப்பில் காட்டும்.

          கட்டக் கொள்கை · Cell policy

          • Unicode NFC-க்குப் பின் ஒரு grapheme cluster = ஒரு கட்டம். இரு பகுதி உயிர்க்குறிகள் (ெ ே ை ொ ோ ௌ) ஒருபோதும் பிரிக்கப்படுவதில்லை.
          • ஸ்ரீ = ஒரு கட்டம்; க்ஷ = இரு கட்டங்கள் (க் + ஷ). Zero-width எழுத்துகள் நீக்கப்படும்.
          • விடை ஒப்பீடு எழுத்துக்கு எழுத்து — க ≠ கா ≠ க்.

          செயலியாக நிறுவ · Install as an app

          • Android / Chrome, Edge: மேலே உள்ள ⬇ நிறுவு பொத்தான், அல்லது உலாவி மெனுவில் Install app / Add to Home screen.
          • iPhone / iPad (Safari): பகிர் ▸ முகப்புத் திரையில் சேர்.
          • கணினி (Chrome, Edge): முகவரிப் பட்டையின் வலப்புறம் உள்ள நிறுவு ஐகான்.
          • நிறுவியதும் இரு கட்டத் தொகுப்புகளும் சாதனத்திலேயே சேமிக்கப்படும் — இணையம் இல்லாமலும் விளையாடலாம்; முன்னேற்றம் சாதனத்தில் மட்டுமே இருக்கும்.
