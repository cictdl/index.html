# திருக்குறள் இலக்கணக் குறிப்பு — கட்டுப்படுத்தப்பட்ட சொற்களஞ்சியம் (Controlled Tag-set v1)

இந்தக் கோப்பு, 1330 குறள்களுக்கும் **சொல்வாரியான இலக்கணக் குறிப்பு (word-level grammatical tag)** வழங்கப் பயன்படும் நிலையான tag-set ஐ வரையறுக்கிறது. ஒவ்வொரு சொல்லுக்கும் ஒரு **primary tag** இந்தப் பட்டியலிலிருந்து தேர்ந்தெடுக்கப்படும்; கூடுதல் விவரம் `features`, `vetrumai`, `gloss` புலங்களில் இடம்பெறும்.

> அலகுகள்: **சீர் (sira)** = யாப்பு அலகு (இடைவெளியால் பிரிந்தது); **சொல் (sol)** = இலக்கண அலகு. ஒரு சீர் ஒன்றுக்கு மேற்பட்ட சொற்களைக் கொண்டிருக்கலாம் (எ.கா. "கசடறக்" = கசடு + அற). tag சொல் அளவில் தரப்படும்; சீர் அமைப்பு யாப்புக்காகப் பாதுகாக்கப்படும்.

`பெயர்` · `வினை` · `இடை` · `உரி`

## B. primary `ilakkanam` tags (closed vocabulary)

### B1. பெயர்ச்சொல் வகை (category = பெயர்)
| tag | விளக்கம் |
|---|---|
| `பொருட்பெயர்` | பொருளின் பெயர் (மரம், பொன், அன்பு) |
| `இடப்பெயர்` | இடம் (உலகு, நிலம்) |
| `காலப்பெயர்` | காலம் (நாள், பின், ஞான்று) |
| `சினைப்பெயர்` | உறுப்பு (கை, அடி, கண்) |
| `பண்புப்பெயர்` | பண்பு/குணம் (இனிமை, கடுமை) |
| `தொழிற்பெயர்` | வினையடியாய்ப் பிறந்த பெயர் (கல்வி, கொடை, ஓட்டம்) |
| `எண்ணுப்பெயர்` | எண் (ஒன்று, ஆயிரம்) |
| `சுட்டுப்பெயர்` | சுட்டு (அது, இது, அவன், அவை) |
| `வினாப்பெயர்` | வினா (யார், எது, எவன்) |
| `சிறப்புப்பெயர்` | இயற்/சிறப்புப் பெயர் (வள்ளுவன்) |
| `காரணப்பெயர்` | காரணத்தால் அமைந்த பெயர் |
| `இடுகுறிப்பெயர்` | காரணமின்றி இடப்பட்ட பெயர் |
| `வினையாலணையும்பெயர்` | வினைமுற்றுப்போல் நின்று பெயராவது (சேர்ந்தார், கற்பவை, வாழ்வார்) |

### B2. வினைச்சொல் வகை (category = வினை)
| tag | விளக்கம் |
|---|---|
| `தெரிநிலைவினைமுற்று` | காலம் வெளிப்படும் முற்று (ஏகினான், சேர்ந்தார்) |
| `குறிப்புவினைமுற்று` | காலம் மறைந்து பண்பு உணர்த்தும் முற்று (உரியர், செல்வர்) |
| `ஏவல்வினைமுற்று` | கட்டளை (செய், கேள்) |
| `வியங்கோள்வினைமுற்று` | வாழ்த்து/விதி/வேண்டல் (கற்க, நிற்க, வாழ்க) |
| `வினையெச்சம்` | வினை கொண்டு முடியும் எச்சம் (செய்து, ஏகி, அற) |
| `பெயரெச்சம்` | பெயர் கொண்டு முடியும் எச்சம் (செய்த, வரும், கற்ற) |
| `எதிர்மறைவினையெச்சம்` | (செய்யாது, இன்றி) |
| `எதிர்மறைபெயரெச்சம்` | (செய்யாத, இல்லாத) |

### B3. இடைச்சொல் வகை (category = இடை)
| tag | விளக்கம் |
|---|---|
| `வேற்றுமைஉருபு` | ஐ, ஆல், கு, இன், அது, கண் … |

| `உம்மை` | "உம்" (எண்/எச்ச/சிறப்பு/இழிவுசிறப்பு) |
| `ஏகாரம்` | தேற்றம்/பிரிநிலை/வினா ஏ |

## C. தொகைநிலைத் தொகை — compound சீர்க்கு `togai` field (6)
ஒரு சீர் தொகையாக இருப்பின் (உருபு/இடைச்சொல் மறைந்து):
| tag | மறைந்தது | எ.கா. |
|---|---|---|
| `வேற்றுமைத்தொகை` | வேற்றுமை உருபு | மலர்மிசை, நிலமிசை |
| `வினைத்தொகை` | காலம் | நீடுவாழ்வார், செம்மாந்து |
| `பண்புத்தொகை` | பண்பு+பெயர் | மாணடி, பைந்தொடி |
| `உவமைத்தொகை` | உவம உருபு | முத்தநகை, மலர்க்கண் |
| `உம்மைத்தொகை` | உம் | இரவுபகல், தாய்தந்தை |
| `அன்மொழித்தொகை` | பிறிதொன்றைக் குறித்தல் | பொற்றொடி (=அவள்) |

## F. யாப்பு — `yappu` (குறள் வெண்பா; deterministic + judged)
- `paa` = **குறள் வெண்பா** (1330-க்கும் பொது)
- `sirCount` = [முதல் அடி, ஈற்று அடி] — பெரும்பாலும் [4,3]
- `monai` — அடிதோறும் சீர்களின் முதல் எழுத்து ஒப்பு (இனமோனை உட்பட: க/ங, ச/ஞ, ட/ண, த/ந, ப/ம, ற/ன)
- `edugai` — அடிமுதல் சீர்களின் இரண்டாம் எழுத்து ஒப்பு
- `thalai` — வெண்டளை
- `eetruseer` — ஈற்றுச்சீர் (தனிச்சொல்) வாய்பாடு: நாள்/மலர்/காசு/பிறப்பு

## H. confidence + review
ஒவ்வொரு சொல் tag-க்கும் `confidence` (0–1). எந்த சொல்லும் ஐயத்திற்குரியதாயின் `reviewFlags` இல் சேர்க்கப்படும். **இந்த annotation AI-உதவியுடன் உருவாக்கப்பட்ட draft; இறுதி ground-truth-க்கு தமிழ் இலக்கண அறிஞர் சரிபார்ப்பு தேவை.**
