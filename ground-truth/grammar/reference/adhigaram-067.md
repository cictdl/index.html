## குறள் 661
> வினைத்திட்பம் என்பது ஒருவன் மனத்திட்பம்  
> மற்றைய எல்லாம் பிற.

*யாப்பு:* குறள் வெண்பா · சீர் [4, 3] · மோனை அடி2 'ம/ப(இனம்)' · ஈற்றுச்சீர் பிறப்பு
*அணி:* சொற்பொருட்பின்வருநிலை
*பொருள்:* ஒரு தொழிலின் திட்பம் என்று சொல்லப்படுவது ஒருவனுடைய மனதின் திட்பமே (உறுதியே) ஆகும், மற்றவை எல்லாம் வேறானவை.

| சீர் | தொகை | சொல் | பிரிப்பு | இலக்கணக் குறிப்பு | வகை | வேற்றுமை | நம் |
|---|---|---|---|---|---|---|---|
| வினைத்திட்பம் | வேற்றுமைத்தொகை | வினைத்திட்பம் | வினை + திட்பம் | பண்புப்பெயர் | பெயர் | அது (6, உடைமை) | 0.70 |
| என்பது |  | என்பது | என்(வினை) + பது | வினையாலணையும்பெயர் | பெயர் |  | 0.70 |
| ஒருவன் |  | ஒருவன் | ஒரு + வன் | பொருட்பெயர் | பெயர் | அது (6, உடைமை) | 0.66 |
| மனத்திட்பம் | வேற்றுமைத்தொகை | மனத்திட்பம் | மனம் + திட்பம் | பண்புப்பெயர் | பெயர் | அது (6, உடைமை) | 0.68 |
| மற்றைய |  | மற்றைய | மற்றை + அ | பண்புப்பெயர் | பெயர் |  | 0.58 |
| எல்லாம் |  | எல்லாம் | எல்லா + அம் | பொருட்பெயர் | பெயர் |  | 0.68 |

**⚑ பார்வைக்கு:**
- என்பது: வினையாலணையும்பெயர் vs குறிப்புவினைமுற்று ஐயம்; இங்கே 'எனப்படுவது' பெயர்ப் பொருளில் வினையாலணையும்பெயர் கொள்ளப்பட்டது.
- மற்றைய: சுட்டடியாய் அமைந்த பெயரடை; சுட்டுப்பெயர் (மற்று சுட்டெழுத்து அன்று) அன்றி பண்புப்பெயர் ஆகத் திருத்தப்பட்டது.

## குறள் 662
> ஊறொரால் உற்றபின் ஒல்காமை இவ்விரண்டின்  
> ஆறென்பர் ஆய்ந்தவர் கோள்.

*யாப்பு:* குறள் வெண்பா · சீர் [4, 3] · மோனை அடி2 'ஆ' · எதுகை 'ற' · ஈற்றுச்சீர் காசு
*பொருள்:* இடையூறு வருவதற்கு முன்பே நீக்குதல், வந்த பின் தளராமை ஆகிய இந்த இரண்டினது வழியே வினைத்திட்பம் பற்றி ஆராய்ந்தவரின் கொள்கையாம்.

| சீர் | தொகை | சொல் | பிரிப்பு | இலக்கணக் குறிப்பு | வகை | வேற்றுமை | நம் |
|---|---|---|---|---|---|---|---|
| ஊறொரால் | வேற்றுமைத்தொகை | ஊறொரால் | ஊறு + ஒரால் | தொழிற்பெயர் | பெயர் | ஐ (2, செயப்படுபொருள்) | 0.55 |
| உற்றபின் |  | உற்ற | உறு + த்த (அ) | பெயரெச்சம் | வினை |  | 0.64 |
|  |  | பின் | பின் | காலப்பெயர் | பெயர் |  | 0.68 |
| ஒல்காமை |  | ஒல்காமை | ஒல்கு + ஆமை | தொழிற்பெயர் | பெயர் |  | 0.62 |
| இவ்விரண்டின் |  | இவ் | இ + வ் | சுட்டுப்பெயர் | பெயர் |  | 0.60 |
|  |  | இரண்டின் | இரண்டு + இன் | எண்ணுப்பெயர் | பெயர் | இன் (5, நீங்கல்/ஒப்பு) | 0.60 |
| ஆறென்பர் |  | ஆறு | ஆறு | பொருட்பெயர் | பெயர் |  | 0.60 |

| கோள் |  | கோள் | கொள் → கோள் | தொழிற்பெயர் | பெயர் |  | 0.64 |

**⚑ பார்வைக்கு:**
- ஊறொரால்: 'ஊறு + ஒரால்(=ஒரீஇதல்)' பிரிப்பும் வேற்றுமை எண்ணும் ஐயம்; தொழிற்பெயர் vs வேற்றுமைத்தொகை.
- இவ்விரண்டின்: 'இன்' உருபு 5-ஆம் வேற்றுமை vs உடைமை (ஆறு) பொருள்தரும் சாரியை ஐயம்.

## குறள் 663
> கடைக்கொட்கச் செய்தக்க தாண்மை இடைக்கொட்கின்  
> எற்றா விழுமந் தரும்.

*யாப்பு:* குறள் வெண்பா · சீர் [4, 3] · ஈற்றுச்சீர் மலர்
*அணி:* முரண்
*பொருள்:* செய்யும் செயலை முடிவில் வெளிப்படும் படியாக செய்யும் தகுதியே ஆண்மையாகும், இடையில் வெளிபட்டால் நீங்காத துன்பத்தைக் கொடுக்கும்.

|---|---|---|---|---|---|---|---|

- எற்றா: எதிர்மறைப் பெயரெச்சம் (எற்றாத) vs உரிச்சொல் ஐயம்; பிரிப்பு உறுதியற்றது.
- செய்தக்க: தாண்மையை விளக்கும் பெயரெச்சம் ஆகத் திருத்தம்; வினையாலணையும்பெயர் கொள்கை மறுக்கப்பட்டது.
