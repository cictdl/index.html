*பொருள்:* அறிவுடையவர் (வேறொன்றும் இல்லாதிருப்பினும்) எல்லாம் உடையவரே ஆவர், அறிவில்லாதவர் வேறு என்ன உடையவராக இருப்பினும் ஒன்றும் இல்லாதவரே ஆவர்.

**⚑ பார்வைக்கு:**
- 'என்னுடைய ரேனும்' = என்ன + உடையர் + ஏனும் (என்ன உடையவராயினும்); சீர்-சந்தி பகுப்பு ஐயம்; 'உடையர்' adi2-pos2 சீருடன் இணைத்துக் கொள்ளப்பட்டது.
- 'ரேனும்' = (உடைய)ர் + ஏனும்; 'ஏனும்' உம்மையாகக் கொள்ளப்பட்டது (அசைநிலை இடையே ஐயம்).
- 'இலர்' = இல் + அர் (பலர்பால் எதிர்மறை முற்று); எதிர்மறைவினைமுற்று எனத் திருத்தப்பட்டது (முன்பு குறிப்புவினைமுற்று).
