| கோடி |  | கோடி | கோடி | எண்ணுப்பெயர் | பெயர் |  | 0.85 |

**⚑ பார்வைக்கு:**
- 'உறும்' குறிப்புவினைமுற்று ('நன்மையாகும்/மேலாகும்' உரைப்படி); உறு+உம் தெரிநிலைவினைமுற்று எதிர்காலம் ('will accrue/befit') எனவும் கொள்ளலாம்
- 'பக்கததுள்' = பக்கத்து(side, இடப்பெயர்) + உள்(7ஆம் வேற்றுமை உருபு)
- 'மந்திரியின்' 5ஆம் வேற்றுமை இன் ஒப்பு/ஒப்பீடு ('minister-ஐ விட')
- 'எழுபது கோடி' தெவ்வோர்-க்கு அடைமொழி (எண்)

## குறள் 640
> முறைப்படச் சூழ்ந்தும் முடிவிலவே செய்வர்  
> திறப்பாடு இலாஅ தவர்.

*யாப்பு:* குறள் வெண்பா · சீர் [4, 3] · மோனை அடி1 'மு', அடி2 'தி/த' · ஈற்றுச்சீர் காசு
*அணி:* முரண்
*பொருள்:* (செயல்களைச் முடிக்கும்) திறன் இல்லாதவர், முன்னே எண்ணி வைத்திருந்தும் (செய்யும் போது) குறையானவைகளையேச் செய்வர்.

| சீர் | தொகை | சொல் | பிரிப்பு | இலக்கணக் குறிப்பு | வகை | வேற்றுமை | நம் |
|---|---|---|---|---|---|---|---|
| முறைப்படச் |  | முறைப்பட | முறை+படு+அ | வினையெச்சம் | வினை |  | 0.70 |
| சூழ்ந்தும் |  | சூழ்ந்து | சூழ்+ந்த்+உ | வினையெச்சம் | வினை |  | 0.80 |
|  |  | உம் | சூழ்ந்து+உம் | உம்மை | இடை |  | 0.78 |
| முடிவிலவே |  | முடிவில | முடிவு+இல்+அ | எதிர்மறைபெயரெச்சம் | வினை |  | 0.60 |
|  |  | ஏ | முடிவில+ஏ | பிரிநிலைஇடை | இடை |  | 0.70 |
| செய்வர் |  | செய்வர் | செய்+வ்+அர் | தெரிநிலைவினைமுற்று | வினை |  | 0.82 |
| திறப்பாடு |  | திறப்பாடு | திறம்+பாடு | பண்புப்பெயர் | பெயர் |  | 0.70 |
| இலாஅ |  | இலா | இல்+ஆ | எதிர்மறைபெயரெச்சம் | வினை |  | 0.72 |
| தவர் |  | அவர் | (இலாஅத்)+அவர் | சுட்டுப்பெயர் | பெயர் |  | 0.72 |

**⚑ பார்வைக்கு:**
- 'இலாஅ தவர்' = 'இலாத அவர்' புணர்ச்சி; 'இலா' எதிர்மறைபெயரெச்சம், 'த' (இலாத-இன் இறுதி) + 'அவர்' சுட்டுப்பெயர்; 'இலாஅ' அளபெடை
- 'முடிவில' = முடிவு+இல்(எதிர்மறை)+அ; எதிர்மறைபெயரெச்சம் பெயராய் நின்றது (செய்வர்-இன் செயப்படுபொருள் 'அரைகுறை செயல்கள்'); எண்/பால் நீக்கப்பட்டது; 'ஏ' பிரிநிலை இடை
- 'திறப்பாடு இலாஅ தவர்' = எழுவாய் 'திறன் இல்லாதவர்'; 'திறப்பாடு' இலா-வின் செயப்படுபொருள்
- 'முறைப்படச்' = முறைப்படு+அ வினையெச்சம் (adverbial 'methodically')
